## Sonuç / Ticket amacı
GitHub monorepo içinde Java/Spring Boot ve Next.js çalışan iskeletini, lokal DB ortamını ve ilk health endpoint/shell UI oluştur.

## Kabul kriterleri
- [ ] Java 25 + Spring Boot 4.1.x Maven wrapper ile derlenir; exact patchler pinlidir.
- [ ] Next.js TypeScript strict pnpm lockfile ile build edilir; AppShell sayfası render olur.
- [ ] Docker Compose ile lokal PostgreSQL açılır; Flyway örnek migration uygulanır.
- [ ] README lokal kurulum/env.example komutları ve başarısızlıkta troubleshooting içerir.

## Zorunlu doğrulama

## Kapsam dışı
