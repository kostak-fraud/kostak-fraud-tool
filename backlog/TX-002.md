## Sonuç / Ticket amacı
Gerçek zamanlı sentetik generator ve idempotent persistent ingestion kur.

## Kabul kriterleri
- [x] Wallet/POS/Physical POS için seedli deterministic risk/normal transaction üretilir.
- [x] Her işlem stable idempotency key ile DB’ye yazılır; unique constraint ve conflict guard duplicate kaydı önler.
- [x] Tenant başına kalıcı next_sequence transaction insertleriyle aynı DB transaction içinde ilerler; restart sonrası sıra devam eder.
- [x] Tenant admin için yetkili API üzerinden start/stop ve 1–10 işlem/saniye kontrolü vardır; global environment kill-switch default kapalıdır.

- [x] DB’de pending/processing/processed/failed evaluation_state review_status alanından ayrıdır.

## Zorunlu doğrulama
- [x] Seeded scenario unit tests; Testcontainers duplicate/restart/rate-limit/channel persistence integration; tenant-admin authorization API testleri

## Kapsam dışı
Gerçek banka API/PAN/IBAN kullanma.

## Risk / preflight kontrolü
Worker kapasitesi ve DB pool sınırı.
