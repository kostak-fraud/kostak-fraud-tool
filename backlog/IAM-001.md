## Sonuç / Ticket amacı
Tenant, kullanıcı üyeliği, izin modeli ve Supabase Auth JWT doğrulamasını backend’e entegre et.

## Kabul kriterleri
- [ ] JWT signature, issuer/audience/expiry kontrolleri çalışır; geçersiz token reddedilir.
- [ ] User-to-tenant membership server-side resolve edilir ve tenant-scoped queries uygulanır.
- [ ] Viewer/Analyst/Rule Author/Admin izinleri endpointe göre 403 verir.
- [ ] Tenant A tokenı tenant B kaydını okuyamaz; CI integration test bunu ispatlar.

## Zorunlu doğrulama
- Testcontainers cross-tenant+403 integration

## Kapsam dışı
Tam kullanıcı daveti/abonelik/SaaS onboarding yok.

## Risk / preflight kontrolü
Auth provider yapılandırması ve tenant RLS kritik.
